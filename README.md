# 通用版考试模拟器

面向 Windows x64 的离线练习工具。导入自定义题库后，自动统计总题量和题型分布。每场采用百分制，支持作答计时、错题重测、练习记录和闪卡。多个题库的练习数据分别保存在本机。

## 导入题库

支持 `.xlsx`、`.docx`、UTF-8 `.csv` 和 UTF-8 `.tsv`。可复制[示例 CSV](examples/question-bank.csv)，或用同样的列名创建 Excel 工作表、Word 表格。Excel 可以使用多个工作表，每个题目表需要自己的表头。

| 题型 | 题干 | 选项A | 选项B | 选项C | 正确答案 |
| --- | --- | --- | --- | --- | --- |
| 单选题 | 一小时等于多少分钟？ | 30 | 60 | 90 | B |
| 多选题 | 以下哪些数是偶数？ | 2 | 3 | 4 | AC |
| 判断题 | 正方形的四条边一样长。 | | | | 正确 |

- 「题干」和「正确答案」是必填列。选择题可填写 A 到 H 的连续选项。「题型」留空时根据选项和答案推断，建议为只有一个正确选项的多选题显式填写题型。
- 单选答案可填写 `A`，多选可填写 `AC` 或 `A,C`。判断题可省略选项并填写「正确」或「错误」。
- Word 正文也可以使用 `1. 题干` 或 `第1题` 开头，选项按 `A. 文字` 分行，最后另起一行写 `答案：A`。可用「单选题」「多选题」「判断题」作分组标题。
- 每份题库最多支持 10,000 题，题干和选项合计不超过 500 万字符。解析错误会显示位置，修正后即可重新导入。

## 组卷和计分

混合组卷优先按单选 70%、多选 10%、判断 20% 抽题。某种题型数量不足时，从其他可用题型补足。每场最多 100 题，当前题池少于 10 题时可以练完题池。

单选、多选和判断的每题权重分别为 1、2、0.5。百分制得分按 `得分权重 / 本场总权重 × 100` 计算。正确率按答对题数计算，多选须与标准答案完全一致。

## 从源码构建

在 x64 Windows 10 或 11 上打开 PowerShell 7，执行以下命令。第一次构建会从 NuGet 和微软下载 WebView2 SDK 与离线运行时安装包，并校验下载内容。

```powershell
pwsh -File .\build-fast.ps1
```

打开 `dist\通用版考试模拟器.exe`。把程序复制到其他电脑时，请保留 `运行组件\离线安装包`。缺少的系统运行时会在首次启动时安装，安装 .NET Framework 可能需要管理员确认。

要迁移自己的题库、历史和进度，请先退出程序，再复制 `题库数据` 文件夹。程序在本地读取题库并保存记录。
